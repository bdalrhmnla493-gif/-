# رفيق القرآن

تطبيق أندرويد عربي أصلي باستخدام Kotlin وJetpack Compose.

## الوظائف الموجودة في الإصدار التجريبي
- مصحف عثماني محلي يضم السور الـ114 والآيات الـ6236.
- البحث في أسماء السور وفتح السورة وقراءة الآيات دون اتصال.
- حفظ آخر موضع قراءة.
- سبحة رقمية تحفظ الذكر المختار والعداد محليًا.
- مظهر فاتح وداكن وتلقائي.

## مصدر نص القرآن
نص القرآن العثماني وبيانات السور من مشروع Tanzil Project، وتم إدراج النص كما ورد دون تعديل.
راجع ملف الترخيص داخل مجلد assets والرابط https://tanzil.net.

## البناء والاختبارات
يشغّل GitHub Actions اختبارات الوحدة ثم يبني APK تجريبيًا عند تحديث فرع التطوير أو main.
